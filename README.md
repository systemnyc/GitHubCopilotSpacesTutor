# GitHub Copilot Spaces Tutorial Projects

Welcome to the **GitHub Copilot Spaces Tutorial Repository**! This repository is being developed to provide hands-on Python projects designed to help you practice and understand GitHub Copilot Spaces fundamentals.

## 📚 What You'll Learn

This repository is structured to guide you through each step of working with Copilot Spaces:

1. **Context Grounding** - Understand how curated context improves Copilot's accuracy
2. **Adding Documentation** - Expand with requirements and specifications
3. **Custom Instructions** - Tailor Copilot's responses to your project
4. **Multi-file Context** - Work with interconnected modules
5. **Team Collaboration** - Share expertise across team members

## 🚀 Quick Start

Each project directory contains:
- **README.md** - Project-specific instructions and learning objectives
- **main.py** (or application files) - The primary implementation
- **tests/** - Automated unit tests
- **docs/** - Documentation and specifications (in later projects)

## 📖 How to Use This Repository

1. Start with [01_context_baseline](./01_context_baseline/README.md)
2. Read each project's README before beginning
3. Follow the hands-on exercises in each project
4. Run the automated tests to verify your understanding
5. Observe how context affects Copilot's responses
