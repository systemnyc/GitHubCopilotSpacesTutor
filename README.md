# GitHub Copilot Spaces Tutorial Projects

Welcome to the **GitHub Copilot Spaces Tutorial Repository**! This repository is being developed to provide hands-on Python projects designed to help you practice and understand GitHub Copilot Spaces fundamentals.

## 📚 What You'll Learn

This repository is structured to guide you through each step of working with Copilot Spaces:

1. **Basic Project Setup** - Start with simple scripts and basic context
2. **Adding Context & Documentation** - Expand with docs and specifications
3. **Custom Instructions** - Tailor Copilot's responses to your project
4. **Multi-file Projects** - Work with interconnected modules
5. **Team Collaboration** - Share expertise across team members

## 🗂️ Project Structure

```
GitHubCopilotSpacesTutor/
├── README.md                              # This file
├── 01_weather_app/                        # Step 1: Basic Project
├── 02_todo_list/                          # Step 2: Adding Documentation
├── 03_calculator_api/                     # Step 3: Custom Instructions
├── 04_data_analyzer/                      # Step 4: Multi-file Project
└── 05_team_dashboard/                     # Step 5: Collaboration Setup
```

## 🚀 Quick Start

Each project directory contains:
- **main.py** - The primary Python script
- **README.md** - Project-specific instructions
- **docs/** - Documentation and specifications (in later projects)
- **tests/** - Unit tests (in later projects)

## 📖 How to Use This Space

1. Open each project folder in sequence
2. Read the project README
3. Use Copilot Chat to ask questions about the code
4. Observe how context affects Copilot's responses
5. Compare responses with and without added context
